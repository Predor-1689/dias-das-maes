# 🌸 Homenagem Dia das Mães

Site interativo para presentear sua mãe no Dia das Mães. Contém contador de tempo, cartão de memórias, linha do tempo, player de música com letra e uma carta personalizada.

## 🚀 Como usar

1. **Edite os nomes e datas** — Abra o `index.html` e procure pelos comentários `🔧 EDITAR`. Lá você encontra tudo que pode personalizar:
   - Nome da sua mãe
   - Seu nome
   - Data de nascimento (no JavaScript)
   - Mensagens, carta, letra da música, etc.

2. **Coloque sua música** — Substitua o arquivo `musica01.mp3` pelo de sua preferência e ajuste o `src` no `<audio>`.

3. **Abra no navegador** — Dê um clique duplo no `index.html` para ver como ficou.


## 📁 Estrutura

```
copia_anonimizada/
├── index.html       # Página principal (edite aqui)
├── style.css        # Estilos visuais
├── musica01.mp3     # Sua música (substitua)
└── README.md
```
Caso altere a musica, você pode alterar a letra tambem

## 🛠️ Feito com

HTML, CSS e JavaScript puro — sem dependências externas (apenas Google Fonts).
